# Project RealtySec
### ISO/IEC 27001:2022 – Information Security Management System (ISMS) Learning Project

## About the Project

Project RealtySec is a fictional information security GRC project based on a hypothetical real estate organisation in India.

I started this project as part of my learning in Governance, Risk and Compliance (GRC), with a focus on understanding the requirements of ISO/IEC 27001:2022 and how they can be applied within an organisation.

The project is being developed step by step alongside my ISO 27001 training and mentor-led sessions. Each section is documented as I complete the relevant learning module.

The purpose is to understand the standard and gain practical experience in preparing information security governance and compliance documentation.

## Project Objectives

The main objectives of this project are to:

- Understand the requirements of ISO/IEC 27001:2022.
- Define the context and scope of a fictional organisation's ISMS.
- Understand leadership responsibilities and information security policies.
- Learn how to identify, analyse and treat information security risks.
- Understand the selection and implementation of information security controls.
- Become familiar with ISMS documentation and audit requirements.

## Organisation Scenario

**Organisation:** RealtySec  
**Industry:** Real Estate  
**Business Location:** India  
**Project Type:** Fictional learning scenario

For this project, RealtySec is used as a sample organisation to understand how information security requirements may apply to a business handling customer information, employee records, property documentation and information shared with external service providers.
